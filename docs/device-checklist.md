## A. 收據照片 ⚠️ 最高風險

`expo-image-manipulator` 的壓縮與檔案搬移都只做過型別檢查。

1. 新增支出 → 拍收據 → 允許相機權限
2. 預期：縮圖立刻出現，標示「待上傳」
3. 稍等後重整，預期：「待上傳」消失
4. **離線拍一張**：飛航模式下拍照 → 縮圖照樣出現且標「待上傳」
   → 恢復連線後自動送出
5. 長按縮圖可以移除

## B. 離線寫入與佇列

1. 飛航模式 → 新增 3 筆、改 1 筆、刪 1 筆 → 畫面應立即反應
2. 關飛航 → 用網頁版對照，**數量與內容完全一致**
3. **順序反過來測**：先刪一筆、再新增兩筆。舊版的話新增也會被堵住，
   新版應該全部通過——這是驗證佇列不再卡死的關鍵
4. 同步途中反覆開關網路 3–5 次 → **不得出現重複資料**

## C. 多幣別與跨幣別結算

1. 記一筆 JPY、一筆 TWD
2. 結餘頁預期：兩個幣別**分開顯示**，不會被換算合併
3. 結算 → 記錄還款 → 選「用其他幣別支付」→ 自己填匯率
4. 預期：餘額只動「債的幣別」，實付金額只是紀錄

## D. 四種分帳方式

平均分以外的都沒實測過。各記一筆：

- 依權重（例如 2:1:1）
- 依百分比（總和必須剛好 100%）
- 指定金額（總和必須等於總額）

每一種都確認「分攤加總與金額相符」那行有出現。

## E. 編輯支出時移除成員

編輯一筆支出，把某個原本有分攤的人取消勾選再儲存。
這條走的是子表軟刪除，跟先前那個刪除 bug 是相鄰的程式碼。

## F. 邀請與加入

1. 成員頁 → 產生邀請連結 → 分享
2. 另一台裝置或無痕視窗點開連結 → 填名字 → 確認彈窗顯示正確的群組名稱
3. 確認後直接進入群組，人數 +1
4. App 內用邀請碼加入（跟連結是不同路徑）

## G. 身分與救援

1. 帳號頁 → 綁定 Email → 收 6 位數驗證碼 → 完成
2. 預期：身分編號**不變**（畫面最下方顯示前 8 碼）
3. 另一台裝置用同一個 Email 找回身分，群組應該跟著回來

## H. 兩台裝置一起用

你和朋友各自記幾筆，互相確認看得到對方的支出、餘額一致。
